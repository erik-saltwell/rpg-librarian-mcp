# Library organization and cleanup skill

Workshop completed 2026-10-11. The accepted direction is a callable LLM review of catalog relationships, comparable to a code review of the library's organization. Clear-cut corrections proceed automatically; judgment calls become recommendations in the existing review workflow.

The central improvement is reviewing related groups rather than isolated entries. Each correction is coherent and atomic, and each finding explains its evidence and before-and-after organization. Database-backed decisions and coverage allow later calls to resume progress without repeatedly challenging intentional choices. A concise invocation receipt makes autonomous work visible.

The accepted behavior and approved quality rubric are recorded in [intent.md](intent.md). Workshop ended because remaining questions concern design and implementation evidence rather than worthwhile additions to the concept. At workshop completion, implementation had not begun.
